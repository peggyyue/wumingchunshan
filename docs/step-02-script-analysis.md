# 蛾仙选祭录 · 剧本分析

## 故事梗概

古代山村中，年轻村女阿绣被选中，在木然村民的注视下吞下干枯蛾翅。她对身体变化生出欣喜，却逐渐被鳞纹、湿丝与遥远吟唱牵引，走向祭台上的人形蚕茧；直到丝线遮眼，她才骤然惊觉。姐姐赠予蓝色绣花鞋、随后消失于浓雾的童年记忆插入，映照眼前的失去。茧壳裂开后，一道带湿翼的双辫背影隐入夜色，只留下空茧与绣花鞋，以安静压抑的方式呈现仪式许诺与自我消失之间的冲突。

## 类型定位

- 主类型：民俗恐怖
- 副类型：志怪奇幻 / 悬疑
- 关键词：古代山村、选祭仪式、异化、蚕茧、姐妹记忆

## 全局影像风格

国风写实的古代中式山村民俗恐怖影像，以潮湿浓雾中的晒场、祭台和旧屋构成乡村空间；低饱和青绿色冷调统领画面，幽绿灯火、幽蓝光点与暗金微光局部点缀，保持中等对比。采用轻微胶片颗粒、中等锐度与高动态范围保留暗部湿丝及旧织物细节，以低调光统摄雾中漫射日光、油灯烛火和微弱顶光的混合光质，持续营造安静、压抑、克制而诡异的氛围；不出现现代物件、字幕、文字、水印、血腥画面或完整怪物。

### 视觉风格

以国风写实表现中式山村志怪民俗，依靠局部异化细节和遮蔽的怪异轮廓建立恐怖感，不展示血腥或完整怪物。

- 关键词：国风写实、中式民俗、志怪、局部异化、遮蔽表达

### 色彩

低饱和青绿色冷调主导，以幽绿灯火、幽蓝光点和暗金微光作局部点缀，中等对比维持雾层与暗部细节。

- 色板：青绿色为主，幽绿、幽蓝与暗金局部点缀
- 色温：整体偏冷，局部暗金微暖
- 饱和度：低
- 对比度：中

### 影像质感

轻微胶片颗粒与中等锐度保留皮肤鳞纹、湿丝和旧织物的真实质感，高动态范围兼顾低照度暗部与微弱发光细节。

- 胶片颗粒：轻微
- 锐度：中等
- 动态范围：高

### 光线基调

整体采用低调光，雾中漫射日光、幽绿油灯与烛火、蓝色蜡烛及微弱顶光构成混合光质，局部暗金微光短暂显露而不照亮全部异形。

- 用光：低调光
- 光源：雾中日光、油灯、烛火、微弱顶光、茧内暗金微光
- 光质：混合

### 世界环境

古代中式乡村环境，由潮湿多雾的山村晒场、祭台与阿绣旧屋组成，不出现现代物件。

- 时代：古代
- 环境：乡村

### 情绪

以安静、压抑、克制的仪式进程持续积累诡异感，阿绣短暂的欣喜与姐姐记忆中的温柔反衬最终的失去。

- 关键词：安静、压抑、克制、诡异、失落
